# Pope Francis - Biography

## Project Overview
This project is a biography webpage dedicated to Pope Francis, the head of the Catholic Church from 2013 until his death in 2025. It features an informative layout utilizing Tailwind CSS for styling, which highlights key aspects of his life, including his early years, Jesuit background, and papacy. The webpage is designed to be user-friendly and visually appealing, making use of fonts and icons to enhance the user experience.

## Installation
To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/pope-francis-biography.git
   ```
   
2. **Navigate into the project folder:**
   ```bash
   cd pope-francis-biography
   ```

3. **Open the `index.html` file in your web browser:**
   Simply double-click the `index.html` file or right-click and choose to open it with your preferred web browser.

## Usage
Once the webpage is open in your browser, you can navigate through different sections using the fixed navigation menu. Each link will take you to various sections of the biography, providing detailed information about Pope Francis's life, including:

- About Pope Francis
- Early Life
- Jesuit Years
- Key Achievements and Legacy during Papacy

## Features
- **Responsive Design:** The webpage is designed to be responsive, adapting to different screen sizes and devices.
- **Smooth Navigation:** Fixed navigation to easily access sections of the biography.
- **Visual Enhancements:** Integration of images, icons, and styled components for better engagement.
- **Tailwind CSS Integration:** Utilizes Tailwind CSS for a modern and stylish layout.
- **Content Sourcing:** Information is presented in a structured manner to provide clarity.

## Dependencies
The project primarily relies on the following libraries:

- [Tailwind CSS](https://tailwindcss.com/)
- [Font Awesome](https://fontawesome.com/)

These are included through CDN links in the `index.html` file, thus no additional installation is required.
